# Easy Commute

## 🚗 Overview

Easy Commute is an AI-powered carpooling platform that connects commuters traveling on similar routes across Islamabad and Rawalpindi. The platform helps users reduce travel expenses, decrease traffic congestion, and promote sustainable transportation through intelligent ride matching.

## 🎯 Problem Solved

Many students and professionals travel daily using private vehicles, resulting in high fuel costs, traffic congestion, and increased carbon emissions. Easy Commute provides a smart carpooling solution that makes daily travel more affordable, efficient, and environmentally friendly.

## 🌐 Live Demo

https://easy-commute-kappa.vercel.app

## ✨ Features

- Search available rides
- Offer a ride
- Smart ride matching
- Interactive map
- My Trips dashboard
- AI Commute Assistant
- Fuel cost estimation
- CO₂ savings estimation
- Responsive user interface

## 🤖 AI Feature

The AI Commute Assistant uses Google's Gemini AI model to answer commuting questions, recommend suitable rides, estimate travel savings, and provide personalized transportation suggestions.

## 🚀 Run Locally

### Prerequisites

- Node.js

### Installation

```bash
npm install
```

### Environment Variables

Create a `.env.local` file and add:

```env
GEMINI_API_KEY=your_api_key_here
```

### Start the Application

```bash
npm run dev
```
